# V4 maximum-frequency baseline

Airborne classification now scales fit residuals and curvature by apparent ball width/height, allowing supported partial arcs without an interior apex. The fit must improve on a straight-line fit, have downward image-space curvature, sufficient travel/curvature, and bounded size-normalized residual. This tolerates image scale, anisotropic scaling and linear camera pan; it is not a calibrated projective reconstruction. Camera cuts still reset histories. Missing archive tracking is marked unavailable. Rebuilt QM30 has 555 accepted arc fragments, versus 140 before; increased acceptance is not an accuracy measurement.

Every retained frame runs robot/fuel inference on one full-width field crop, robot tracking, flight tracking, hub localization, and OCR on every detected robot. Scoreboard OCR covers every source frame, reusing reads from the lightweight boundary prepass at matching frame indices. The prepass remains a planning scan at 2 Hz; each frame's scoreboard OCR result is acquired once and reused. Inactive pre/post-match frames continue to skip object inference. Playback outputs every retained frame for new runs. No automatic frame-rate reduction is enabled.

Scoreboard confirmation now requires a 0.25-second span, preventing adjacent 60-Hz reads from prematurely confirming a transient reading. Status/failure records separate full-frame scoreboard OCR time and robot identity OCR time from aggregate analysis time.

Validation: 73 tests passed, including partial arcs, scale invariance, linear camera pan, straight-motion rejection, per-frame coverage, and time-based OCR confirmation. CUDA smoke test on a half-second active excerpt: 30 frames in 81.74 seconds (1.84 seconds boundary prepass, 79.07 seconds analysis). This ran while archived overlays were rebuilding, so it is not an isolated full-match performance result; nevertheless it indicates a substantial cost increase. The complete-match baseline has been queued with the existing 3,540-second internal deadline and 3,600-second external kill limit. Incomplete runs retain partial evidence and are not marked complete. Frequency tuning is deferred until measured results are available.

## Playback frame synchronization

Existing completed archives now publish two-second JSON chunks under static/playback, with one record for each archived source frame. The overlay manifest references chunks, preserves the airborne catalog, and reports source_fps. The browser fetches nearby chunks into a bounded cache and selects detections using requestVideoFrameCallback.mediaTime with half-frame tolerance. Missing chunks display a loading state rather than holding old detections. Seeking clears stale presentation timestamps. No interpolated positions are invented. Older robot archives still contain repeated positions between their original detector updates; new every-frame robot evidence requires the ongoing reprocessing.

Verification on QM30: desktop/mobile selected exact consecutive archive indices 5700–5711; live playback produced 68 distinct rendered frames with zero timestamp-to-frame mismatches. These checks establish correct matching to presented frames, not a guarantee that a browser decodes/presents every source frame under load. 74 tests pass, including full archive coverage, chunk boundaries and explicit skipped frames. Also fixed an uninitialized hub-overlay reference on pre-match skipped frames found by regression tests.

## Cubic trajectory filtering

Playback classification version 4 retains quadratic acceptance and adds a cubic fallback. Cubic fitting uses normalized time and apparent ball size, requires at least 16 observations spanning 0.2 seconds, at least a 25% residual improvement over the quadratic fit, and the existing error/travel/curvature bounds. Positive vertical acceleration at both endpoints ensures downward curvature throughout the cubic segment, rejecting S-shaped fits. Straight and noisy tracks remain rejected. The filter continues to display recorded points rather than extrapolated model predictions. Tests cover cubic flight, scaled cubic flight, S-shaped rejection and noisy-line rejection; 76 tests pass. This change concerns airborne playback classification; it does not validate a made score.
